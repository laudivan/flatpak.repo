# Antigravity (Unofficial) Flatpak Packaging

This repository contains the Flatpak packaging manifest and build definitions for **Antigravity (Unofficial)**, an Agentic Development Platform.

> [!NOTE]
> This is an Unofficial community-maintained package. Generated by AI using Antigravity and cureted by ~{l4u}.
> The packaging uses the Flatpak `extra-data` mechanism to dynamically fetch the official Linux `x86_64` and `aarch64` (ARM64) binaries directly from https://antigravity.google during installation without redistributing proprietary assets directly inside this repository.

## Technical Specifications

- **Application ID**: `io.github.laudivan.antigravity`
- **Supported Architectures**: `x86_64`, `aarch64` (ARM64)
- **Runtime**: `org.freedesktop.Platform` (branch `24.08`)
- **SDK**: `org.freedesktop.Sdk` (branch `24.08`)
- **Base Application**: `org.electronjs.Electron2.BaseApp`
- **Payload Method**: Dynamic `extra-data` source per architecture.
- **Permissions**:
  - `--share=network`: Remote agent communications, extensions, and network connectivity
  - `--share=ipc`: Inter-process communication
  - `--socket=x11`, `--socket=wayland`, `--socket=fallback-x11`: Modern display server support
  - `--device=dri`: Hardware/GPU graphics acceleration
  - `--socket=pulseaudio`: Audio support
  - `--filesystem=home`: Home dir access for workspace and project directories

## Local Build Instructions (Fedora Linux)

Follow these steps to set up the build environment, build the Flatpak package locally, and test execution on Fedora:

### 1. Install Flatpak and Flatpak Builder
```bash
sudo dnf install -y flatpak flatpak-builder
```

### 2. Add the Flathub Remote Repository
```bash
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
```

### 3. Install Required Runtimes and BaseApp
```bash
flatpak install -y flathub \
  org.freedesktop.Platform//24.08 \
  org.freedesktop.Sdk//24.08 \
  org.electronjs.Electron2.BaseApp//24.08
```

### 4. Configure Upstream URL & Checksum per Architecture
Update the `extra-data` sources in `io.github.laudivan.antigravity.json` with the production size and sha256 checksums for each respective architecture:
- `x86_64`: `Antigravity.tar.gz`
- `aarch64`: `Antigravity.tar.gz`

### 5. Build and Install Locally for Testing
```bash
# Build for your host architecture (native x86_64 or aarch64)
flatpak-builder --user --install --force-clean build-dir io.github.laudivan.antigravity.json

# (Optional) Build explicitly targeting ARM64 / aarch64
flatpak-builder --arch=aarch64 --user --install --force-clean build-dir io.github.laudivan.antigravity.json
```

### 6. Run the Locally Installed Application
```bash
flatpak run io.github.laudivan.antigravity
```

### 7. Uninstall Test Build
```bash
flatpak uninstall --user io.github.laudivan.antigravity
```
